## PDF 第126頁：買い物 ― 買い物で使われることば

### ① 通信販売（インターネットで）

買い物のしかた：
- 商品をカート（買物かご）に入れます。
- 支払い方法を選びます。（クレジットカード・銀行・代金引換＝配達員に代金を支払う方法）
- ご注文金額が5,000円を超える場合、送料は無料です。
- 注文内容を確認します。
- 領収書の必要な方はお知らせください。
- ご注文の翌日配達も承ります。

| 词语 | 读法・意思 |
|---|---|
| 販売する | 販売する（はんばいする）・销售 |
| 商品 | 商品（しょうひん）・商品 |
| 支払う | 支払う（しはらう）・支付 |
| 方法 | 方法（ほうほう）・方法 |
| 配達する | 配達する（はいたつする）・投递 |
| 金額 | 金額（きんがく）・金额 |
| 超える | 超える（こえる）・超过 |
| 無料 | 無料（むりょう）・免费 |
| 確認する | 確認する（かくにんする）・确认 |
| 領収書 | 領収書（りょうしゅうしょ）・收据 |
| 翌日 | 翌日（よくじつ）・翌日 |

### ② カタログ・ショッピング

ご注文書例：商品名「財布」、色・サイズ「青」、数量1、金額5,250、送料0、お支払い金額5,250。※届け先＝商品を届けてほしい場所。

| 词语 | 读法・意思 |
|---|---|
| 客 | 客（きゃく）・客人、顾客 |
| 届ける | 届ける（とどける）・送到 |
| 財布 | 財布（さいふ）・钱包 |
