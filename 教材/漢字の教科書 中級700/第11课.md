### 「ロールキャベツ」（4人分）の作り方

#### 材料

| 材料 | 数量 |
|---|---|
| キャベツ | 8枚（まい） |
| ひき肉 | 200g |
| 玉ねぎ | 1/2個（こ） |
| ベーコン | 8枚（まい） |
| 塩・胡椒 | 少々（しょうしょう） |
| パン粉 | 1/2カップ |
| 牛乳 | 大さじ2杯（はい） |

#### スープの材料

| 材料 | 数量 |
|---|---|
| 玉ねぎ | 1個（こ） |
| にんじん | 1本（ほん） |
| セロリ | 1本（ほん） |
| 固形スープ | 1個（こ） |
| トマト缶 | 1缶（かん） |
| 水 | 2カップ |

#### 作り方

1. スープの野菜（玉ねぎ、にんじん、セロリ）を細切りにしておきます。
2. 大きいなべに湯を沸かし、キャベツをゆでて軟らかくしておきます。
3. 玉ねぎを細かく刻み、フライパンで炒めます。
4. ③にパン粉と牛乳を入れて混ぜ、さらにひき肉と塩・胡椒を入れて混ぜます。
5. ④を8等分し、丸めます。
6. ⑤をキャベツで包み、ベーコンを巻きます。
7. ⑥をスープの材料と一緒になべに入れ、火にかけます。最初は強火で、その後、弱火で30分煮たらできあがりです。
