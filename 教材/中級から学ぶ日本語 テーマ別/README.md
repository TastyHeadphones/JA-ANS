## 使用建议

- 先看 `课程详细总结.md` 了解全书主题、对应教材页码和学习顺序。
- 学具体一课时，先核对“教材完整词汇清单”（按 PDF《新しい言葉》的四列原始顺序），再学习带中文释义与例句的重点词汇。
- 单课文件是教材内容的基准版本；“重点词汇”会补充课文中的高频词，因而不取代完整词汇清单。
- 再按“文法要点 → 课文梳理 → 练习题 → 复习要点”逐节学习；语法均附用法、接续、例句、说明。
